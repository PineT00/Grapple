# 유니티 C# 스크립트 코딩 컨벤션

## 대원칙
- **Unity 6 기준:** 모든 C# 스크립트는 Unity 6 버전을 기준으로 생성하고 수정합니다.
- **최신 API 사용:** Unity 6에 맞춰 업데이트된 최신 API를 사용합니다.
  - 예: `Rigidbody.velocity` 대신 `Rigidbody.linearVelocity`를 사용합니다.

## 추가 원칙
- **객체 지향 설계:** 캡슐화, 상속, 다형성을 활용하여 코드를 모듈화하고 재사용성을 높입니다.
- **유지보수성:** 다른 개발자가 쉽게 이해하고 수정할 수 있도록 명확하고 일관된 코드를 작성합니다.
- **주석 작성:** 코드의 의도가 명확하지 않거나, 복잡한 로직이 포함된 부분에만 간결하게 주석을 작성합니다. 모든 줄에 주석을 다는 것은 지양합니다.
- **네이밍 컨벤션:** C# 표준(클래스/메소드는 PascalCase, 변수는 camelCase)을 따릅니다.
- **단일 책임 원칙 (SRP):** 하나의 클래스나 메소드는 하나의 기능만 책임지도록 설계합니다.
- **성능 최적화:** `Update()` 와 같이 매 프레임 호출되는 함수에서는 불필요한 연산을 최소화합니다.
- **기존 코드활용:** 새로운 코드를 작성하기 전에 기존 코드를 확장, 수정하여 활용할 수 있는지 검토합니다.
