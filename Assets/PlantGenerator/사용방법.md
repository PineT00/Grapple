# PlantGenerator 사용 방법

## 📋 전체 흐름 개요

1. **브랜치 프리팹** 만들기 (예: 줄기, 잎, 꽃 등)
2. **PlantSpecies** 데이터 만들기 (루트 브랜치 지정)
3. **PlantGenerator** 컴포넌트로 식물 생성

---

## 🌱 단계별 상세 가이드

### 1단계: 첫 번째 브랜치 프리팹 만들기 (루트/줄기)

#### 1-1. 기본 오브젝트 생성
```
Hierarchy에서:
1. 우클릭 > 3D Object > Capsule 생성
2. 이름을 "Root Branch"로 변경
3. Capsule Collider 컴포넌트는 이미 자동으로 추가되어 있음
4. BranchTemplate 스크립트 컴포넌트 추가
```

**Hierarchy 구조:**
```
Root Branch (오브젝트)
  ├─ MeshFilter (컴포넌트) - 자동 생성됨
  ├─ MeshRenderer (컴포넌트) - 자동 생성됨
  ├─ Capsule Collider (컴포넌트) - 자동 생성됨
  └─ BranchTemplate (컴포넌트) - 직접 추가
```

#### 1-2. Transform 및 Collider 설정

**⚠️ 중요: 캡슐을 Z축 방향으로 눕혀야 합니다!**

```
Inspector에서 Root Branch의 Transform:
- Position: (0, 0, 0)
- Rotation: (0, 0, 90) ← 캡슐을 Z축으로 눕힘
- Scale: (0.2, 0.5, 0.2) ← 얇고 긴 줄기 모양

Inspector에서 Capsule Collider:
- Center: (0, 0, 0.5) ← 캡슐이 원점에서 시작해서 +Z방향으로 1만큼 뻗음
- Radius: 0.1
- Height: 1
- Direction: Z-Axis (2번)
```

**왜 이렇게 해야 하나요?**
- 브랜치는 항상 **로컬 원점(0,0,0)에서 시작**해서 **+Z방향으로 성장**합니다
- Collider의 Center를 (0,0,0.5)로 설정하면 Height가 1일 때 0부터 1까지 뻗습니다
- Rotation (0,0,90)으로 캡슐을 눕히면 기본 Y축 방향이 Z축으로 바뀝니다

#### 1-3. BranchTemplate 설정
```
Inspector에서 BranchTemplate:
[성장 제약]
- Depth Min: 0 (루트는 깊이 0에서 시작)
- Depth Max: 0 (루트는 깊이 0에만 존재)
- Max Count: 1 (루트는 1개만)

[충돌 검사]
- Obstacle Layers: Default (벽 등 피할 레이어)
- Surface Layers: 0 (루트는 표면 필요 없음)

[회전 파라미터]
- Max Pivot Angle: 0 (루트는 회전 안함)
- Max Roll Angle: 0
```

#### 1-4. 소켓 추가 (다른 브랜치가 연결될 지점)

**소켓은 브랜치의 자식 오브젝트로 추가합니다:**

```
Hierarchy에서:
1. Root Branch 우클릭 > Create Empty
2. 새로 생긴 GameObject 이름을 "Socket [0]"로 변경
3. Socket [0] 선택 후 Inspector에서:
   - Position: (0, 0, 1) ← 브랜치 끝 (Height가 1이므로)
   - Rotation: (0, 0, 0)
   - Scale: (1, 1, 1)
4. BranchSocket 스크립트 컴포넌트 추가
```

**최종 Hierarchy 구조:**
```
Root Branch
  └─ Socket [0] (자식 오브젝트)
       └─ BranchSocket (컴포넌트)
```

**소켓을 더 추가하려면 (최대 4개):**
```
Socket [1]: Position (0.2, 0, 0.5) ← 중간 오른쪽
Socket [2]: Position (-0.2, 0, 0.5) ← 중간 왼쪽
Socket [3]: Position (0, 0.2, 0.7) ← 중간 위쪽
```

**⚠️ 중요: 소켓의 BranchOptions는 아직 비워둡니다!**

#### 1-5. 프리팹으로 저장
```
Root Branch를 Project의 Assets/PlantGenerator/ 폴더로 드래그
→ "RootBranch.prefab" 생성됨
→ Hierarchy에서 Root Branch 삭제
```

### 2단계: 두 번째 브랜치 프리팹 만들기 (일반 줄기)

#### 2-1. 같은 방식으로 GameObject 생성
```
Hierarchy에서:
1. 우클릭 > 3D Object > Capsule 생성
2. 이름: "Stem Branch"
3. Transform:
   - Rotation: (0, 0, 90) ← Z축으로 눕힘
   - Scale: (0.15, 0.4, 0.15) ← 루트보다 약간 얇게
4. Capsule Collider:
   - Center: (0, 0, 0.4) ← Height 0.8의 절반
   - Height: 0.8
   - Radius: 0.08
   - Direction: Z-Axis
5. BranchTemplate 컴포넌트 추가
6. 자식으로 Socket [0], Socket [1] 추가 (1-4단계 참고)
   - Socket [0]: Position (0, 0, 0.8) ← 끝
   - Socket [1]: Position (0, 0, 0.4) ← 중간
```

#### 2-2. BranchTemplate 설정 (다르게!)
```
[성장 제약]
- Depth Min: 1 (루트 다음부터 생성)
- Depth Max: 5 (깊이 5까지만)
- Max Count: 20 (최대 20개)
- Quota Percent: 60 (전체 식물의 60%까지)

[회전 파라미터]
- Max Pivot Angle: 30 (±30도 랜덤 회전)
- Max Roll Angle: 180 (360도 회전 가능)
- Grow Upwards: 0.3 (약간 위쪽으로 성장)
```

#### 2-3. 프리팹으로 저장
```
→ "StemBranch.prefab" 생성
```

---

### 3단계: 세 번째 브랜치 프리팹 만들기 (잎 - 표면 스냅 예시)

#### 3-1. 잎 오브젝트 생성
```
Hierarchy에서:
1. 우클릭 > 3D Object > Quad 생성 (평평한 잎 모양)
2. 이름: "Leaf Branch"
3. Transform:
   - Rotation: (0, 0, 0)
   - Scale: (0.3, 0.3, 1)
4. Capsule Collider 컴포넌트 추가 (Quad는 콜라이더가 없음)
   - Center: (0, 0, 0.15)
   - Height: 0.3
   - Radius: 0.08
   - Direction: Z-Axis
5. BranchTemplate 컴포넌트 추가
6. 소켓은 추가하지 않음! (잎은 끝 노드)
```

#### 3-2. BranchTemplate 설정 (표면 붙는 잎)
```
[성장 제약]
- Depth Min: 2
- Depth Max: 10
- Max Count: 100
- Quota Percent: 40

[충돌 검사]
- Obstacle Layers: Default
- Surface Layers: Default ← 이걸 설정하면 표면에만 붙음!
- Surface Distance: 1.2 ← 표면과의 최대 거리

[회전 파라미터]
- Max Pivot Angle: 45
- Grow Upwards: 0 (벽에 딱 붙음)
- Face Upwards: true ← 잎이 항상 위를 향함
```

#### 3-3. 프리팹으로 저장
```
→ "LeafBranch.prefab" 생성
```

### 4단계: 소켓에 브랜치 옵션 연결하기 ⭐

**이제 여기가 핵심입니다!**

#### 4-1. RootBranch 프리팹 열기
```
Project에서 RootBranch.prefab 더블클릭 (프리팹 편집 모드)
```

#### 4-2. Socket [0] 설정
```
Inspector에서 BranchSocket:
- Branch Options 배열 크기: 1
- Element 0:
  - Template: StemBranch (드래그)
  - Probability Percent: 100
```

**의미: "이 소켓에서는 100% 확률로 StemBranch가 자란다"**

---

#### 4-3. StemBranch 프리팹 열기
```
Project에서 StemBranch.prefab 더블클릭
```

#### 4-4. Socket [0] 설정 (자기 자신 + 잎)
```
Inspector에서 BranchSocket:
- Branch Options 배열 크기: 2
- Element 0:
  - Template: StemBranch (자기 자신!)
  - Probability Percent: 70
- Element 1:
  - Template: LeafBranch
  - Probability Percent: 30
```

**의미: "이 소켓에서 70%는 줄기가 계속 자라고, 30%는 잎이 난다"**

#### 4-5. Socket [1] 설정 (잎만)
```
- Branch Options 배열 크기: 1
- Element 0:
  - Template: LeafBranch
  - Probability Percent: 100
```

**의미: "이 소켓에서는 100% 잎만 난다"**

### 5단계: PlantSpecies 만들기

```
Project에서:
1. 우클릭 > Create > Plant Generator > Plant Species
2. 이름: "My Plant Species"
3. Inspector에서:
   - Root Branch: RootBranch (프리팹 드래그)
   - Max Total Branches: 50
```

---

### 6단계: 식물 생성하기

```
Hierarchy에서:
1. 빈 GameObject 생성 (이름: "My Plant")
2. PlantGenerator 컴포넌트 추가
3. Inspector에서:
   - Species: My Plant Species (드래그)
   - Seed: 원하는 숫자 (같은 숫자면 같은 모양)
4. PlantGenerator 컴포넌트 우클릭 > Regrow Plant

→ 식물이 자라기 시작합니다!
```

## 🎯 핵심 개념 정리

### BranchSocket의 역할
- 각 브랜치의 "연결점" 역할
- **Branch Options**에 "여기서 어떤 브랜치가 자랄 수 있는지" 정의
- 확률을 다르게 해서 다양성 부여

### 브랜치 연결 예시
```
RootBranch (깊이 0)
  └─ Socket [0] → StemBranch (70%) or LeafBranch (30%)
                     └─ Socket [0] → StemBranch (70%) or LeafBranch (30%)
                     └─ Socket [1] → LeafBranch (100%)
```

### Depth (깊이) 개념
- Depth 0: 루트
- Depth 1: 루트에서 직접 자란 브랜치
- Depth 2: Depth 1 브랜치에서 자란 브랜치
- ...

BranchTemplate의 Depth Min/Max로 "이 브랜치는 몇 단계에서만 자랄 수 있다" 제한

## 🌿 담쟁이 덩굴 만들기 팁

```
BranchTemplate 설정:
- Surface Layers: Wall (벽 레이어)
- Surface Distance: 1.5
- Grow Upwards: 0.5 (위로 올라감)
- Max Pivot Angle: 20 (너무 휘지 않게)

벽 오브젝트:
- Layer를 "Wall"로 설정
- Collider 필수
```

## 🐛 문제 해결

**식물이 안 자라요!**
- PlantSpecies의 Root Branch가 설정되어 있나요?
- RootBranch의 소켓에 Branch Options가 있나요?
- Console 로그 확인

**브랜치가 너무 많이/적게 자라요!**
- PlantSpecies의 Max Total Branches 조절
- BranchTemplate의 Max Count, Quota Percent 조절

**담쟁이가 벽에 안 붙어요!**
- 벽에 Collider가 있나요?
- Surface Layers가 벽의 Layer와 맞나요?
- Surface Distance를 크게 해보세요
